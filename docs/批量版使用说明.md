# 漏磁 CSV 批量处理与归档

## 使用方法

1. 第一次使用，在项目终端执行 `python -m pip install -r requirements.txt`。
2. 把待处理的漏磁信号 CSV 放进项目的 `input` 文件夹。
3. 双击根目录的“运行批量处理.bat”，或执行 `python mfl_analysis.py`。
4. 在 `output` 查看处理结果 CSV 和波形对比图。
5. 处理成功的原始 CSV 自动移入 `input_pre`。失败或跳过的文件留在 `input`。

这三个目录均相对程序位置确定，与启动终端的位置无关；不存在时自动创建。

```text
项目/
  mfl_analysis.py
  mfl_enhancements.py
  requirements.txt
  运行批量处理.bat
  input/                         人工放入待处理 CSV
  input_pre/                     已成功处理的原始 CSV
  output/
    batch_summary_运行时间.csv
    实验文件名/
      run_运行时间/
        processed_signals.csv
        processing_comparison.png
        reference_candidates.png
        candidate_features.csv
        parameter_comparison.csv
        parameter_comparison.png
        ...
```

## 归档和失败处理

- 只有该文件的全部信号处理和输出完成后才归档，原始 CSV 内容不变。
- input_pre 中同名文件不会被覆盖，后续文件加 `_1`、`_2` 等编号。
- 汇总表记录 input_file、status、output_directory、resampled_rows、archived_file、source_sha256 和 message。校验值用于核对归档原件。
- success 表示完成处理和应执行的归档，不等于确认缺陷全部检出。
- 缺少 ts、pos、f9–f15 的表在批量模式下标为 skipped；单文件模式标为 failed。
- 数据或处理错误标为 failed；结果目录有 FAILED.txt，不应把其中可能存在的中间输出当作完整结果。
- 处理成功但归档失败时标为 archive_failed；完整结果保留，原文件留在 input，可按错误信息检查权限或占用。
- 有处理失败或归档失败时返回非零退出码，仍继续处理其他文件。
- 只扫描输入目录顶层 .csv（含 .CSV），不会递归扫描 output、input_pre 或输入子文件夹。再次运行不会处理已归档文件。
- 没有 CSV 时提示并保存空汇总表。如需重新分析，把 input_pre 的原件复制回 input，再运行即可。
- 不要在运行过程中编辑或替换输入文件；检测到内容改变时不归档。

## 指定其他输入与参数

```powershell
python mfl_analysis.py --mean-window 5
python mfl_analysis.py "D:\其他实验数据文件夹"
python mfl_analysis.py "D:\其他实验数据文件夹\实验.csv" --out "D:\其他结果目录"
```

默认结果始终写入项目 output；外部输入保留原位，只有项目 input 内的原始文件会自动归档。显式指定 input 内单个文件同样会归档。默认每次生成新的运行子目录；只有 --overwrite 才覆盖同名结果。

## 分析条件与元数据

仍使用 f9–f15、10<pos<800、1 个位置单位重采样、SG 1 阶 81 点和 10 点均值滤波。本次只调整文件流程，不改变信号处理算法。

单位从输入旁的 manifest.json 读取；在 input 中使用时，可将适用于整批数据的 manifest.json 放在 input，JSON 不会被处理或归档。没有元数据时标为原始单位，不猜测单位。来自不同采集配置的数据不要共用不匹配的 manifest；可指定原采集目录的 CSV 单独处理。原数据位于 raw 时会查找上级 manifest.json。

不同扫描范围用 --pos-min、--pos-max 调整。其他参数见“新版使用说明.md”，其中旧文件选择和路径行为由本说明替代。同一批命令参数适用于全部文件，实物标注或通道偏移不同时应分批运行。
