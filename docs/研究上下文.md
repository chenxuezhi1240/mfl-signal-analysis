# 已确认的项目背景

本项目从用户对缺陷钢筋漏磁检测数据的分析任务整理而来，当前保存的是文件夹批量版代码。

## 实验信息

- 原数据共 2370 点，持续 12.995 s。用户明确 f1–f8 未使用。
- 数据包 manifest 标注位置单位 mm、信号单位 Gs。
- 设备配置为两台八通道 DAQ，9–15 标注为磁信号，第16路为位移；没有具体测量方向。
- metadata 的缺陷描述为 3 notch(2mm,2mm,3mm)，提离11 mm，目标速度50 mm/s。三个实际缺口的位置及尺寸标记含义尚未确认。
- 起点附近 t≈3.480 s 出现约1.3333倍多通道缩放，与配置 sensitivity 一致，但生效原因没有日志证实。
- 选定 10<pos<800 的单向片段有1160点，重采样后为11–799 mm共789点。
- 默认 f13 参考候选约109、403 mm；不意味着只有两处实物缺陷。多通道分组数也不能替代缺口数。
- 默认10点均值相对仅去背景的 f13 峰值压低约31.7%与34.9%；5点能保留更多峰值，但尚未标定最优参数。

## 方法来源

1. Development of multi-channel magnetic flux leakage testing system for bridge cables，2024，DOI 10.58286/29932：系统采集与噪声检查。
2. A sensor based on multilayer-arranged Hall elements for MFL detection of broken wires in bridge cables，2025，Sensors & Actuators A 391:116668，DOI 10.1016/j.sna.2025.116668：径向差分、SG一阶81点去基线、10点均值和差分叠加。论文阈值1.193 mV不能直接套用Gs数据。

当前默认逐通道方法借鉴其软件步骤；没有确认探头布置前不执行径向差分。新增MAD候选搜索、分组和参数对比为本程序设计，不是完整复现论文ROC。

## 当前验证及后续工作

批量测试已用实测数据副本验证两份正常CSV、一份错误CSV和一份配置表；成功2、失败1、跳过1，并验证原始哈希不变。合成回归测试已纳入tests。

后续优先：补齐实物标注与探头布置，验证第三个缺口响应；用独立重复扫描评估参数、定位误差和误报。尚未实现缺陷尺寸反演、自动通道识别、交互式参数界面。
