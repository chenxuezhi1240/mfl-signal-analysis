# 漏磁信号处理程序 v2

## 运行

将 mfl_analysis.py、mfl_enhancements.py、requirements.txt 放在同一文件夹，在该文件夹打开终端：

```powershell
python -m pip install -r requirements.txt
python mfl_analysis.py
```

选择原始 CSV 后开始处理。也可以传入文件：

```powershell
python mfl_analysis.py "输入.csv" --out results
```

本版本保留旧主流程：f9–f15、10<pos<800、1 mm 重采样、SG 一阶 81 点、均值 10 点。文件须有 ts、pos、f9–f15 列，支持 UTF-8/GB18030；额外辅助列忽略。仍针对该实验格式，不是任意 CSV 自动识别器。

默认每次在 results（未指定则为程序旁 mfl_result）下创建带时间戳的独立运行目录，不覆盖旧结果。只有明确使用 --overwrite 才覆盖指定输出目录。原始输入不修改。

## 新增功能

1. 自动比较 SG 81/121 点与均值 1/3/5/10 点；1 点表示不平滑。不自动选择最佳参数。
2. 每个候选窗口或实物标注窗口内，分别评价七路的峰值保留率、峰位变化。比较使用同一 SG 背景、固定峰极性，防止正负峰互换造成虚假的保留率。与原始数据的绝对偏置值不直接相除。
3. 分别搜索七路正峰和负谷，保留极性、幅值、阈值和位置；检测阈值仍为探索性 MAD 阈值，不是置信度。
4. 根据位置邻近关系分组，列出支持通道，不设置“必须三路支持”等未经验证的门槛。分组最大跨度默认 25 个位置单位，不进行无限延伸的链式合并。
5. 支持手动提供已知通道位置偏移，程序不从波形自动猜测。
6. 支持真实缺口标注，一对一匹配、定位误差和漏检记录。同一候选不能重复命中多个缺口。
7. 用户确认无缺陷区域后，可比较背景标准差；未提供时留空，不擅自指定无缺陷区。

原有 f13 正峰候选和图件继续保留，与新多通道候选并列输出。多通道分组中心是各通道极值位置中心的中位数，不是经传感器标定后的物理缺口中心。双极响应可能被分为多组，邻近真实缺口也可能被合组，组数不能当缺陷数；也可能出现滤波旁瓣，需要与原始曲线核对。

## 调整参数

```powershell
python mfl_analysis.py "输入.csv" --mean-window 5 --out mean5_results
python mfl_analysis.py "输入.csv" --compare-sg-windows 81 121 161 --compare-means 1 3 5 10
```

--sg-window 改变主结果；--compare-sg-windows 改变对照组，主结果参数始终被包含。--compare-means 同理。SG 阶数由 --sg-order 指定，默认为 1。--step 改变重采样间隔，窗口的空间尺度也随之改变。

多通道检测及比较采用所有对比窗口共同的内部有效区，避免把不同边界处理效果当成参数优劣；因此新增候选的边界排除范围可比旧主图更大。窗口大于记录长度时该 SG 对照跳过并记录；共同内部范围不足时停止并提示。

## 真实缺口标注

填写 缺口标注模板.csv：

- defect_id：唯一缺口编号。
- pos：真实缺口位置，使用与 pos 列一致的坐标基准。
- tolerance：允许匹配误差，必须根据位置测量和探头偏置确定，单位同 pos。
- depth_mm、width_mm：可选说明，程序不据此拟合尺寸。

不要直接运行空白模板；不要把 109 或 403 等检测位置伪装成实物标注。

```powershell
python mfl_analysis.py "输入.csv" --labels "已填写标注.csv" --out labeled_results
```

只有确认标注包含分析范围内的全部缺口，才增加 --labels-complete。否则未匹配候选只列为待核对，不计误报。整个容差窗口不在共同可评价区内的标注会被排除评价，并明确标记，不能被计作漏检。

评价仅针对当前参数的多通道分组结果，不是所有参数的独立性能验证。无独立无缺陷样本数量，程序不生成 FPR、准确率或 ROC。需要用独立重复扫描检验参数，不能在同一份标注数据上调参后再宣称泛化准确率。

## 指定无缺陷背景区及位置偏移

```powershell
python mfl_analysis.py "输入.csv" --background-range 500 600 --background-range 250 300
python mfl_analysis.py "输入.csv" --channel-offsets "通道偏移模板.json"
```

背景区数值仅为命令格式示例，必须经实物与原始信号确认再使用。不同 SG 窗口下的背景标准差会受到基线定义影响；不能仅按标准差最小选择参数。

偏移模板默认为空字典 {}，表示不校正。填写格式例如 {"f10": 5.0}，含义为“校正位置=测得位置-5.0”；该数值仅演示语法，不是你的探头校准值。用于分组/匹配的坐标被校正，原始输出曲线和测得位置保留。

## 可选径向差分

保留 --radial-channels 功能，例如 `--radial-channels f9 f10 f11 f12`。这仅是语法示例，只有确认同方向、不同径向提离高度的通道配对后才能采用。该分支另存 radial_difference.csv；默认检测器不使用它。程序会核验相邻差分叠加与两端差分在线性处理下的一致性。

## 本次验证

已在所提供 CSV 上验证：789 个 1 mm 重采样点，原参考正峰仍约为 109、403 mm。10 点均值比 5 点更明显压低尖峰；保留主参数不变以方便与旧结果对照，未将 5 点宣布为最优参数。

合成测试覆盖：正峰和负谷检测、已知通道偏移、分组跨度、一对一标注匹配、边界排除、无候选结果和常量信号。真实数据未提供实物标注或确认背景区，因此本次未生成准确率或背景降噪评价。

文献软件步骤来源：Sun et al., Sensors & Actuators A 391 (2025) 116668，第 4.3 节。新增候选分组、参数对照、标注匹配均为本程序功能，不是文献原有 ROC 流程的完整复刻。
